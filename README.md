# Oficina Digital: versiones

Instaladores de Oficina Digital para Windows. Cada versión está en [Releases](../../releases).

La app instalada busca aquí las versiones nuevas, las descarga, comprueba su huella (sha512) y las instala al cerrarse. Se puede desactivar en Preferencias.

El instalador no está firmado: Windows SmartScreen avisará la primera vez («Más información» y «Ejecutar de todas formas»).
